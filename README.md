# The UX Review Blog 🖥️🔥

A bold and modern UX/design blog website built with **HTML5 and CSS3**, featuring a brutalist-inspired visual style, responsive layouts, interactive hover effects, and multiple content sections.

The project focuses on creating a visually engaging blog experience for readers interested in **technology, design, UX, and digital culture**.

https://mariamashraf-del.github.io/ux-review-blog/

## 📌 Project Overview

**The UX Review** is a modern editorial-style blog landing page designed around a bold and unconventional visual identity.

The website combines strong typography, bright colors, thick borders, shadows, stickers, rotated elements, and interactive effects to create a distinctive **brutalist-inspired UI**.

The page is structured into several sections:

* Navigation Bar
* Hero / Trending Section
* Latest Articles
* Trending Articles
* Categories
* Meet the Authors
* Community Section
* Testimonials
* Newsletter
* Footer

## 🎨 Design Highlights

The design uses a strong visual language based on:

* Thick black borders
* Hard box shadows
* Bright accent colors
* Bold typography
* Rotated elements
* High-contrast sections
* Sticker-style labels
* Interactive hover animations

These elements create a distinctive editorial experience while keeping the interface easy to navigate.

---

## 📱 Responsive Design

The website adapts to different screen sizes using CSS media queries.

On smaller screens:

* Navigation links are hidden and replaced with a menu icon.
* Hero content changes from a two-column layout to a single-column layout.
* Article cards become vertically stacked.
* Author cards are displayed vertically.
* Community content switches to a single-column layout.
* Footer sections become vertically stacked.
* Content widths adjust to fit smaller screens.
